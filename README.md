# Clarear — Site institucional

Site institucional da **Clarear**, GovTech para gestão pública simples e às claras.

Baseado no documento de desenho da marca (01/11/2026).

## Como visualizar

Abra `index.html` no navegador.

## Publicação no GitHub Pages

1. No repositório, vá em **Settings → Pages**.
2. Em **Source**, escolha **Deploy from a branch**.
3. Branch: `main`, pasta: `/ (root)`.
4. Salve. O site ficará disponível em `https://abraaom.github.io/clarear.page/` (pode levar alguns minutos).
